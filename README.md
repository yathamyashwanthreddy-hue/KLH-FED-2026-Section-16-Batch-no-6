# KLH-FED-2026-Section-16-Batch-no-6
Project Description: The system is a combinational logic-based security solution that controls entry into restricted areas. It uses AND, OR, and NOT gates to process binary inputs, granting access when the correct combination is entered and denying it otherwise.  
Components: The required hardware includes logic gates (AND, OR, NOT ICs), a breadboard, a power supply, push buttons or switches for input, LEDs for output, resistors, and connecting wires.  
Working: First, switches provide a binary value (0 or 1) to represent the digital password. Next, the logic gates evaluate this input combination in real time against the programmed logic. Finally, the system outputs a HIGH signal if access is granted, or activates an alarm LED if access is denied.  
Setup Steps: The design and implementation phase consists of four steps:   
Truth Tables: Map all input combinations to their expected outputs.  
Boolean Expressions: Simplify the logic using Boolean algebra.  
Karnaugh Maps: Minimize the number of logic gates needed.  
Simulation: Test the circuits using software like Logisim, Proteus, or Multisim.
